# SIPADES — Sistem Pelayanan Administrasi Desa

Aplikasi multiplatform (Web, Desktop, & Mobile) yang dirancang untuk digitalisasi pelayanan surat-menyurat dan administrasi desa. Proyek ini menggunakan arsitektur satu backend untuk melayani berbagai klien (Web/Desktop & Mobile) sesuai dengan kriteria Tugas Besar.

## Panduan Instalasi & Menjalankan Aplikasi
Pastikan Anda sudah menginstal **Node.js** dan **Flutter SDK** di perangkat Anda.

## Cara Menjalankan Backend:
1. `npm install`
2. Atur file `.env`
3. `npm run dev`

## Cara Menjalankan Mobile:
1. `flutter pub get`
2. `flutter run`
